# Промпт 05: серверная загрузка media fallback для главной страницы

Ты работаешь в проекте `berufsorientierung_app`. Подключи серверную загрузку медиа для главной страницы, но не меняй UI.

Промпт рассчитан на отдельную последовательную сессию: если часть серверной логики уже добавлена, проверь ее на соответствие ТЗ и исправь только расхождения.

## Сбор контекста

1. Перейди в корень проекта `berufsorientierung_app`.
2. Прочитай разделы ТЗ: 8.2, 10, 15 и критерии "Главная страница" из 16.
3. Осмотри файлы:
   - `src/routes/+page.server.ts`;
   - `src/lib/server/db/index.ts`;
   - `src/lib/server/db/eventMedia.ts`;
   - `src/lib/server/db/events.ts`;
   - `src/lib/server/db/reviews.ts`;
   - `src/lib/types/eventMedia.ts`.
4. Если `DB.eventMedia.getHomepageMedia` отсутствует, реализуй минимально необходимую функцию по разделу 8.2 или остановись с явным отчетом, если схема БД тоже отсутствует.

## Задача

Обнови `src/routes/+page.server.ts`:

- сначала загружай активные мероприятия через исправленный `getActiveEvents(db)`;
- если активные мероприятия есть, возвращай их как сейчас и не загружай media для коллажа;
- если активных мероприятий нет, загружай `homepageMedia` через `DB.eventMedia.getHomepageMedia(db)`;
- загрузка отзывов должна остаться best-effort, как в текущем коде;
- ошибка загрузки media не должна ломать страницу: залогируй ее и верни `homepageMedia: []`;
- если БД недоступна, страница возвращает пустые массивы и UI сможет показать fallback-сообщение.
- типизируй `homepageMedia` как `PublicEventMedia[]`;
- во всех return-paths обязательно возвращай `homepageMedia`, даже при ошибке БД или раннем возврате.

Возвращаемая структура должна включать:

- `events`;
- `homepageMedia`;
- `latestReviews`.

## Ограничения

- Не создавай компонент коллажа в этом промпте.
- Не меняй `src/routes/+page.svelte`, кроме минимального типа данных, если текущий код иначе не компилируется.
- Не загружай homepage media, если есть активные мероприятия.
- Не меняй публичную страницу `/events`.

## Проверка

1. Запусти `npm run check`.
2. Проверь, что при ошибке `getHomepageMedia` код не бросает 500.
3. Проверь, что `latestReviews` по-прежнему загружаются best-effort.

## Критерии приемки

- `+page.server.ts` возвращает `homepageMedia`.
- Media загружаются только когда `events.length === 0`.
- Ошибка загрузки media логируется и превращается в пустой массив.
- При недоступной БД публичная главная не должна падать из-за отсутствия `homepageMedia`.
- Проект проходит `npm run check` или причина невозможности проверки описана в отчете.
